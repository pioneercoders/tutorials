#### 1.What is JavaScript?
JavaScript (JS) is a programming language used to make websites interactive and dynamic. Unlike HTML (which structures the content) and CSS (which styles it), JavaScript adds behavior to web pages.

Think of it like this:

  - HTML → the skeleton of a webpage

  - CSS → the clothes and appearance

  - JavaScript → the actions, movements, and interactions

#### 2.Why is JavaScript used?
JavaScript is used to:

Make websites interactive – e.g., buttons that do something when clicked

Update content dynamically – e.g., new data appears without refreshing the page

Validate data – e.g., check if a user entered a valid email in a form

Create web apps – e.g., Google Docs, Gmail, online games

Communicate with servers – e.g., fetch data from a database without reloading the page

#### 3.What are the different data types in JavaScript?
JavaScript has two main categories of data types:

Primitive Data Types – simple values

Non-Primitive (Reference) Data Types – objects and more complex structures

1. Primitive Data Types
   These are basic, single-value types.
   - Number → Any numeric value, like 25 or 3.14.
     Example: let age = 25;

   - String → Text wrapped in quotes, like "Hello" or "Keerthi".
     Example: let name = "Keerthi";

   - Boolean → Represents true or false.
     Example: let isStudent = true;

   - Undefined → A variable declared but not given a value yet.
     Example: let x;

   - Null → Represents empty value or nothing.
     Example: let y = null;

   - BigInt → Very large integers beyond normal number limits.
     Example: let bigNum = 123456789012345678901n;

   - Symbol → Unique value, often used for object properties.
     Example: let id = Symbol('id');
     
2. Non-Primitive (Reference) Data Types

    These are more complex and can store multiple values or objects.

    1.Object → Stores related data as key-value pairs.
           ```javascript
           let person = {name: "Keerthi", age: 25};
```
    2.Array → Ordered list of items.
    ```javascript
    let fruits = ["Apple", "Banana", "Mango"];
```
    3.Function → A reusable block of code that performs a task.
```javascript
function greet() {
  console.log("Hello!");
}
```
    4.Date → Represents date and time.
    ```javascript
    let today = new Date();
```
